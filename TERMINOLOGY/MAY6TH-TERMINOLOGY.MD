# Terminology

## Fiber mass distribution
Histogram measure induced by shell cardinalities.

Not interpreted as a stationary Markov measure.

## Random-walk stationary measure
Degree-weighted stationary distribution of the normalized graph Laplacian.

## KSD graph
Weighted quotient path graph induced by shell decomposition.

## Semiconjugacy
Map satisfying:
Q ∘ K = K̃ ∘ Q
