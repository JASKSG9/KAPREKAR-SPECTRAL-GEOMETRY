Deprecated Claims


This document records claims, conjectures, numerical interpretations,
or terminology from earlier exploratory phases of the project that are
no longer considered part of the validated KSG framework.


The purpose of this file is research transparency and version discipline.



Deprecated or Corrected Claims


1. "Unique Dirichlet-minimal reversible generator"


Previous Claim


The geometric-mean weighted KSG operator was described as the unique
Dirichlet-minimal reversible birth-death generator.


Current Status


Deprecated.


Reason


The geometric-mean weighting
[
W_k = \sqrt{N_k N_{k+1}}
]
does not currently follow from the stated variational principle.


A separate quadratic-budget optimization instead yields harmonic-mean
effective conductances.


The geometric construction is now interpreted as a combinatorial
symmetrization induced by quotient-shell structure.



2. "SUSY spectral pairing"


Previous Claim


The normalized Laplacian spectrum was described using supersymmetry terminology.


Current Status


Relabeled.


Reason


The observed symmetry
[
\lambda_k + \lambda_{n-k} = 2
]
is explained by standard bipartite graph symmetry for normalized Laplacians.


Correct terminology:




bipartite spectral symmetry


normalized Laplacian bipartite pairing




Reference:
Fan Chung, Spectral Graph Theory (1997).



3. "Parity resonance law"


Previous Claim


Parity-based shell resonance structure was claimed statistically significant.


Current Status


Deprecated.


Reason


Subsequent analysis did not support significance beyond exploratory correlation.


No structural theorem currently exists.



4. "\sigma^2 \approx \pi" structural identity


Previous Claim


Variance relationships were interpreted as evidence of hidden structural constants.


Current Status


Open / unresolved.


Reason


The numerical relationship was not consistently reproducible across corrected datasets.


No theorem or mechanism is currently known.



5. Incorrect spectral values from inconsistent normalization


Previous Claim


Several earlier drafts reported spectral values derived from inconsistent
fiber normalizations.


Current Status


Deprecated.


Reason


These computations used incompatible shell vectors or normalization conventions.


Current production-grade spectral values are computed only from verified,
fully enumerated datasets.



Policy Going Forward


Production-grade claims are restricted to:




exhaustively verified computations,


reproducible operator constructions,


formally stated theorems,


explicitly identified conjectures.




Exploratory ideas may remain archived for continuity, but are not treated
as validated mathematics unless promoted through independent verification.
